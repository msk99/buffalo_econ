Buffalo Bioeconomic Model

Financial feasibility of dairy buffalo (Murrah) enterprises in North-West India: bank-ready NPV, IRR, BCR, DSCR and payback, pre- and post-tax, for herds of 5–1,000 adult buffaloes over 5- or 10-year horizons — from a monthly cohort herd engine driven entirely by an editable parameter workbook.

01How it works

The engine couples three sub-models, each answering a different question:

Biological
A monthly cohort herd projection: reproduction on a single calving-interval clock, parity-dependent yield, young-stock rearing pipelines, and a fixed-herd policy in which culling balances the herd at its target size.
Technological
The production requirements of a herd of a given size: ration build-up by animal class, labour in fractional FTE, housing area, and an equipment capacity model — all moving continuously with herd size, so results have no jumps at arbitrary size boundaries.
Economic
Prices the quantities, assembles the operating statement, applies Indian business taxation (entity forms, s.44AD, slab rates — all held in the workbook), structures the bank loan, and computes every viability metric from one cash-flow timeline.

The full method — workbook contract, scaling mathematics, herd engine, taxation and finance — is documented on the technical method page.

02Installation

Requires R ≥ 4.2. Clone, install dependencies, and the setup script runs a self-check (one model projection):

git clone https://github.com/msk99/buffalo_econ.git
cd buffalo_econ
Rscript setup.R

Run the interactive app locally:

R -e 'shiny::runApp("app", launch.browser = TRUE)'

Or use the hosted app directly at khatkar.shinyapps.io/buffalo_planner — no installation needed.
